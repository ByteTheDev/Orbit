Questions

Plain answers, from how the app works today.

Do I need an API key?

No. Orbit starts the Claude Code and Codex command-line tools you already have, and they use their own sign-in.

Where are projects saved?

In one JSON file on your computer. Changes are saved about a second after they are made.

Can two agents change the same file?

They can. Orbit lists each file that two or more agents wrote in the same project.

How do I stop an agent?

Choose Stop on the agent. It shows as stopped and keeps its history, so you can resume it later.

Which models can agents use?

Orbit offers the current Claude and Codex models, each with the thinking levels it supports. Pick one when you launch an agent.

Does Orbit commit my code?

Only if you turn on auto-commit, which commits each finished agent turn. Otherwise you stage and commit files yourself from the Changes tab.

Can agents open web pages?

Yes. An agent can read a page's text and links. You can also open pages in Orbit's built-in browser. On Windows the page shows inside the app; elsewhere you see its text.

Can I change how it looks?

Yes. Settings has six themes, eight accent colours and a setting to reduce motion.
